# Security

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/guardyanz/daily_stock_analysis/security/advisories/new). Include the affected version and minimal reproduction. Do not post credentials, personal reports or exploitable details in a public issue.

This edition is a public beta. The Android client expects a trusted local backend or an explicit ADB tunnel and does not implement the upstream browser login session. Keep provider keys and signing credentials outside version control. Review the [deployment limits](docs/IHSG_EDITION.md) before running a backend beyond your computer.
